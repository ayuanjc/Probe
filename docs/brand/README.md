# 品牌资产（矢量）

一个图形，一条轴线，三个节点。所有文件都由 `ProbeLogo.tsx` 的同一套几何推导：
轴线 (4,36) → (36,4)，三个节点按 t = 0.2 / 0.4 / 0.58 在轴上求值，半径 3.8 / 2.4 / 1.5。
改轴或改点位只改一处，不会出现"某个尺寸里点跑偏了"。

- 底色 `#000000`
- 轴线 `#ffffff` 90%，描边 1.5 / 40 单位，圆头
- 节点 `#3b82f6`（= 全站强调色，纯黑上对比 5.71:1）
- 字标 PROBE：字重 200，字距 0.42em

## 抖音用哪几个

| 用途 | 文件 | 尺寸 | 说明 |
| --- | --- | --- | --- |
| 头像 | `avatar-mark.svg` / `png/avatar-mark.png` | 1:1（1080 / 导出 2160） | 只有图形。头像会被裁成圆形，内容半径 317 < 圆 540 |
| 头像（带字） | `avatar-wordmark.svg` | 1:1 | 图形 + PROBE。缩到 60px 时字就不必读了，但大图看着完整 |
| 主页背景 3:1 | `banner-3x1.svg` | 3000×1000 | 最常用：左图形右字标，右侧大量留白给平台 UI |
| 主页背景 2:1 | `banner-2x1.svg` | 2400×1200 | 偏矮，上下裁切更耐受 |
| 主页背景 4:5 | `banner-4x5.svg` | 1080×1350 | 竖版主页顶部 |
| 横幅 16:9 | `banner-16x9.svg` | 1920×1080 | 居中构图，适合当视频背景/窗口图 |
| 视频封面 9:16 | `cover-9x16.svg` | 1080×1920 | 竖屏封面，主体压在上三分之一 |
| 水印 / 角标 | `mark-transparent.svg` / `lockup-horizontal.svg` | 透明底 | 叠在画面上用；横向锁标留给片尾 |

`png/` 是同一批矢量渲染出来的位图，平台不支持 SVG 时直接传它。

## 为什么留这么多白

抖音头像在列表里只有 40–70px，主页背景又会被昵称、简介、按钮压住中间偏左的一块。
所以：头像只放图形、不放字；横幅把内容集中在左侧 1/3 或正中，右侧留空。
把字标塞到贴边，结果一定是被 UI 裁掉一半。

## 改比例

`sheet.html` 只是预览页（本地打开即可）。要出新的比例，改 `banner-*` 里任何一个的
宽高与三个坐标（图形中心、字标基线、说明行），其余不动即可 —— 图形本身是缩放的，
不会因为画布变化而变形。
